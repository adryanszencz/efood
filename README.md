# efood

Projeto 6 da EBAC: plataforma de restaurantes feita com React + TypeScript.

Site publicado: https://adryanszencz.github.io/efood/

## Parte 1 (exercício 35.10)

- Layout baseado no Figma do efood
- Styled Components para a estilização
- React Router para navegar entre as páginas: Home (`/`) e Perfil do restaurante (`/perfil/:id`)

## Parte 3 (exercício 37.7)

- Carrinho com Redux Toolkit (`slice` do carrinho com adicionar, remover, abrir e fechar)
- O valor total da compra é a soma do preço dos produtos
- Dados dos restaurantes buscados com RTK Query na API da EBAC

## Como rodar

```bash
npm install
npm run dev
```
